# Pi 운영 정책

주 작업자는 Terra high로 고정한다. 코드 변경과 테스트 실행, 자문 반영 판단은 주 작업자가 소유한다. 조사 범위가 넓거나 독립 탐색이 필요한 경우 Luna medium scout를 선택한다. 구조, 모듈 간 상태, 권한, 트랜잭션, 동시성 변경은 구현 전에 Astra medium design 자문을 받는다. 동작을 바꾸는 구현은 완료 전에 Astra medium reviewer가 실제 소스와 수용 조건을 검토한다. 문서와 서식만 바뀌는 작업은 전문 역할 호출 대상에서 제외한다.

Astra를 호출할 수 있다는 설정만으로 역할 수행을 인정하지 않는다. 입력 거부, 프로세스 시작 실패, 모델 실패와 빈 응답을 구분한다. 주 작업자는 정당한 검토 지적을 수정하고 검증하며, 기각하면 이유를 남긴다. 검토 이후 동작이 바뀌면 변경된 범위를 다시 검토받는다. 모든 역할의 기본 추론 강도는 medium이며 필요한 경우 명시적으로 high를 지정할 수 있다.

이 정책은 모델에 주는 실행 지침이다. 런타임이 모든 작업을 자동 분류하거나 자문 품질을 보증하는 것은 아니다. 검토자의 응답은 gdm evidence 또는 gdm-full의 독립 감사 판정을 대신하지 않는다. 실제로 파일을 읽은 기록도 모든 내용을 이해했다는 증거는 아니다.

모델 비교의 효과는 `results-2026-09-09.md`의 기능 검사와 실제 역할 참여를 함께 본다. Astra가 더 낫다는 가정을 점수에 반영하지 않는다. 현재 작은 표본의 결과를 대규모 프로젝트의 안정적인 우열로 확대하지 않는다.
